# CLAIM LAGOS – Training Outline

## Session A – Leadership (30 minutes)
1. Platform purpose: “What action should the campaign take next?”
2. Situation Room tour: KPIs, map, alerts, recommendations
3. Accept vs Reject – human accountability; no auto-publish
4. Reading the executive report
5. Q&A

## Session B – New Media Operations (90 minutes)
1. Login & roles
2. Listen: keywords, ingest, reading sentiment/topics
3. Turning alerts into rapid response (Influence)
4. CREATE + Content approval workflow
5. Ads overview (placeholder metrics vs live)
6. Reports & exports
7. Practice drill: ingest → narrative → recommendation → assign ambassadors

## Session C – Coordinators (60 minutes)
1. Register / verify ambassadors
2. Ward allocation
3. Creating tasks and monitoring completion
4. Leaderboard & badges

## Session D – Digital Ambassadors (30 minutes)
1. Login
2. My Tasks inbox
3. Submitting a report
4. What content they may share (only approved packs; offline/organic as directed)

## Assessment (optional)
- Coordinator completes: register → verify → task → confirm report
- Operator completes: seed keywords → ingest → generate recommendations → accept one
