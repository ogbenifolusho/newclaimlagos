# CLAIM LAGOS – User Guide (New Media Directorate)

## Situation Room (`/`)
- Top KPIs: sentiment, ambassadors, alerts/tasks, share of voice, ward coverage
- Map: Lagos LGAs (public boundaries until official data loaded)
- Live alerts from Listen
- **Recommended Actions**: Review & Assign (select ambassadors) or Reject  
  → Creates internal tasks only — never posts publicly
- Campaign calendar + election countdown
- WebSocket status shows live connectivity

## Digital Ambassadors (`/ambassadors`)
- Register with ward allocation
- Verify pending → active
- Leaderboard by performance score

## My Tasks (`/my-tasks`)
- Ambassadors see assigned tasks
- Submit daily reports → score + badges update

## Listen (`/listen`)
- Seed keyword rules → Run ingest
- View posts, sentiment, topics, alerts
- Without live API keys, synthetic posts exercise the pipeline

## Content (`/content`)
- Create drafts → Approve / Reject
- Approved packs can be distributed as Ambassador tasks

## CREATE (`/create`)
- Calendar events
- AI draft generator → lands in Content as pending review

## Ads (`/ads`)
- Campaigns per platform, budget, synthetic metrics until Ads APIs connected

## Influence (`/influence`)
- Influencer scores
- Rapid response / counter-narrative queue → human approve before any task

## Reports (`/reports`)
- Executive summary
- Narrative detection
- CSV/JSON exports
- Generate recommendations from recent narratives

## Golden rule
**Nothing is published to social platforms automatically.**  
AI only drafts; humans approve; Ambassadors execute offline/organic tasks as directed.
